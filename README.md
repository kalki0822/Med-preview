# MEDSOURCE Healthcare Product Website Demo

A full-page, scroll-driven product discovery website focused only on the client's requirement 2:
- Pharmaceutical products
- Medical devices
- Product sourcing / buy and sell

## Run in Antigravity
```bash
npm install
npm run dev
```

## Visuals and animation
Uses photographic images hosted by Unsplash (see source URLs in `src/App.jsx`). The whole page scrolls normally, with reveal-on-scroll transitions, image parallax, hover zoom, category filtering and a pinned header. It does not use a single sticky 3D scene or illustrated product graphics.

## Before launch
- Replace the temporary MEDSOURCE name with the approved company/client brand.
- Confirm image use and product imagery with the client.
- Connect the enquiry form to an approved backend. It currently shows a local demo confirmation only.
- Confirm product listings, supply claims and applicable regulatory requirements before publishing.
